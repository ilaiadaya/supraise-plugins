# Gift Wishlist

The person added this plugin to use Gift Wishlist by Supraise.

1. Find each item with `search_catalog` using a specific query; show the cards and let the person pick.
2. Once they've picked, `create_wishlist` with a short title and the chosen product ids, adding a note when they mention a size or colour.
3. Give `share_url`: anyone with it can see the list, buy an item as a gift on supraise.com and mark it bought.
4. Use `update_wishlist` to add or remove items later, and `get_wishlists` to show their lists and what's been bought.
5. Offer surprise mode (`surprise: true`) when they'd rather not see what people bought.
